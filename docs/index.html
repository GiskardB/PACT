The open contract for AI agents.

A small, human-readable, vendor-neutral specification for describing what an AI agent is, what it can do, what kind of cognition it provides, and under what basic contract it can operate.

Read the specification Browse examples View on GitHub

Four questions

  • CapabilityWhat can the agent do?
  • CognitionWhat kind of AI capabilities does it provide?
  • ContractUnder what basic conditions may it act?
  • InterfaceHow can another system interact with it?

A minimal manifest

Everything below capabilities is optional.

apiVersion: pact/v1
kind: Agent

metadata:
  name: architecture-agent
  version: 1.0.0

capabilities:
  - architecture-analysis

interfaces:
  - protocol: a2a
    endpoint: https://example.com/a2a

Composes, doesn't replace

PACT is not an agent runtime, framework, orchestration engine, agent-to-agent protocol, tool protocol, governance framework, registry, or LLM API. It's a semantic description and contract layer designed to sit alongside the standards that already handle those jobs.

A2A — agent-to-agent interop MCP — tools, resources, prompts ANP / ADP — decentralized identity & discovery your platform's own governance layer

Status

PACT is a draft, not a released standard — version 0.4, one implementation so far. The intended path is community review and feedback from independent implementations, not a big-bang 1.0 written in isolation. See GOVERNANCE.md for how decisions get made and CONTRIBUTING.md for how to propose a change.
